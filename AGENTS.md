# Harbor & Pine orders (lab)

Instructions for any coding agent in this repo. Harbor & Pine Supply is fictional; all data is made up.

## Commands
- Test: `npm test`. Run it before you say a change is done.

## Rules
- Money is integer cents everywhere. Never use floating-point amounts.
- Work on a branch and open a pull request. Never commit to main.
- Never read or print `.env`. Setting names are in `.env.example`.

## Where things are
- Approved plans: `docs/plans/`. Code: `src/`. Tests: `test/`.
